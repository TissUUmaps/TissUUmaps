Table data can group its columns into sections (`TableData.getColumnSections`, searched with the `sectionId` option of `suggestColumnQueries`, with `describeColumn` and `mapColumn`) and declare column types (`TableData.getColumnType`, with the `TableUtils.loadColumnType` fallback). `MathUtils.countUniqueValues` counts distinct values up to a limit.
