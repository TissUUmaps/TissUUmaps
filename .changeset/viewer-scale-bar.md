Show a scale bar in the viewer when the project's world unit size is set: projects get an optional `worldUnitSize` (the size of one world unit, in micrometers), set with the `setWorldUnitSize` store action, and the `Viewer` of `@tissuumaps/react` gets an `onViewportChange` prop that reports viewport changes without re-rendering
