# AI policy

Quoting from the [napari AI use policy and guidelines](https://napari.org/dev/developers/contributing/ai.html):

> _We are humans who enjoy working with other humans. You may use whatever tools you like, but you are ultimately responsible for the changes you submit. Do not submit changes you have not carefully read through yourself, and let us have a conversation with you, not a chatbot._

TissUUmaps is carefully engineered research software. As such, reproducibility, scientific integrity and attention to detail is of utmost importance. The project strives to facilitate community contributions and long-term maintenance. It is for these reasons that we ask contributors to adhere to the following AI policy:

- Transparently **declare any use of AI** when submitting pull requests
- Use AI as a coding assistant only as long as you **remain 100% familiar\* with the generated code**.
- **Do not submit AI-generated pull requests** unless you have personally verified and tested the generated code.

\* _Contributors must be able to explain the logic of any AI-generated code during the review process as if they had written it themselves._

The use of AI is encouraged for writing documentation (e.g. TSDoc comments) and unit tests _if the alternative would be a lack of such_.

Please be considerate of the societal, environmental, political and economical impacts of AI use in general.

We value human interaction; please limit the use of AI in communication.
